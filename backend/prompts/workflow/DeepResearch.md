## ⚠️ 深度调研工作流

当前查询被识别为需要深度调研的复杂任务。**你必须严格按照以下工作流执行，不得跳过、合并或改变步骤顺序。**

> **输出格式要求：** 在向用户报告进度时，必须使用工作流中原始的三级标题格式，即 `### 步骤N：标题`，不得改为口语化表述。

---

### 步骤一：解析调研主题

首先分析用户的调研需求，明确以下要素，并向用户说明调研框架：

1. **核心主题** — 用户想了解什么
2. **调研维度** — 需要覆盖哪些方面（背景/现状/趋势/争议/数据等）
3. **广度 vs 深度** — 是需要全面概览，还是聚焦某个具体问题

分析完成后进入下一步。

---

### 步骤二：多角度初步搜索

使用 `web_search` 从多个角度搜索相关信息。**每次搜索聚焦一个子维度，可以并行调用：**

1. **主题概况** — 搜索主题的核心定义和基本事实
2. **最新动态** — 搜索最近半年到一年的相关新闻和发展
3. **不同视角** — 搜索正反两面或不同学派的观点（如支持 vs 批评、传统 vs 创新）
4. **数据支撑** — 搜索相关的统计数据、报告、排名等

> ⚠️ 最多搜索 3–5 个不同角度，覆盖主要维度后即停止，不要重复搜索。

初步信息收集完毕后进入下一步。

---

### 步骤三：深入阅读关键文章

检查上一步的搜索结果，**从中挑选 1–3 篇最有价值的文章**，使用 `read_url` 阅读全文：

- 优先选择信源可靠的（权威媒体、学术机构、官方报告）
- 优先选择信息量大的（标题和摘要暗示有深度分析、数据、时间线等）
- 不需要对所有搜索结果都阅读全文，只读最关键的那几篇

阅读完每篇文章后，提取关键信息备用。完成后进入下一步。

---

### 步骤四：检索知识库

调用 `search_knowledge_base` 检查知识库中是否有相关文档。**必须至少发起一次检索尝试。** 建议使用多个不同角度的 query：

- 主题核心术语
- 相关的行业/领域关键词
- 上一步阅读中发现的新的关键概念

也可使用 `search_document_content` 在文档全文中搜索核心术语，定位相关文档。

如果命中文档且需要完整内容，使用 `read_full_document` 或 `read_section` 进一步阅读。完成后进入下一步。

---

### 步骤五：信息交叉验证

综合以上所有信息，检查是否存在以下问题：

1. **信息矛盾** — 不同来源的数据或结论是否冲突？如有，标注矛盾点并说明哪个来源更可靠
2. **信息缺口** — 哪些重要方面信息不足？明确告知用户
3. **时效性** — 所使用的数据是否足够新？标注数据时间点

> 如果发现关键信息缺失，可以补充搜索或阅读一次。完成后进入下一步。

---

### 步骤六：输出结构化调研报告

按以下框架输出深度调研报告：

1. **核心结论** — 用 2–3 句话总结调研发现
2. **背景概述** — 主题的基本背景（让未接触过的读者能理解）
3. **分维度详述** — 每个维度独立成节，包含数据、引用和来源标注
4. **争议与不同观点** — 如有，客观呈现多方立场
5. **信息缺口** — 明确告知哪些方面目前信息不足
6. **参考来源** — 列出所有引用的文章标题和 URL

格式要求：
- 数据和引用必须在行内标注来源（如 `[来源：文章标题]`）
- 关键数据优先使用表格呈现
- 如果报告较长，在开头加目录导航

---

### 步骤七：完整性检查

最终输出前检查以下事项：

- [ ] 是否覆盖了调研主题的各个维度
- [ ] 关键数据是否标注了来源
- [ ] 矛盾和缺口是否如实说明
- [ ] 是否回答了用户的核心问题
- [ ] Markdown 格式是否正确（表格、标题层级）

### 可用工具参考

| 工具 | 用途 |
|------|------|
| `web_search` | 联网搜索多角度信息 |
| `read_url` | 阅读关键文章全文 |
| `search_knowledge_base` | 检索知识库补充资料 |
| `search_document_content` | 在文档全文中搜索关键词，定位相关内容 |
| `list_documents` | 查看知识库文档清单 |
| `read_document_titles` | 查看文档目录，定位相关章节 |
| `read_section` | 阅读文档的特定章节内容 |
| `read_full_document` | 阅读文档全文 |
| `read_chunk_context` | 查看检索片段的前后上下文 |
| `spawn_subagent` | 并行派生子任务调研不同子维度 |
| `set_goal` / `complete_goal` | 管理持续调研目标 |
| `my` | 查看当前配置和工具调用统计 |
| `read_tool_result` | 读取被持久化的工具结果原文（支持分页） |
